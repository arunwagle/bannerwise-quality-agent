# Bannerwise Quality Agent — Design Plan

## Overview
AI-powered banner quality assessment application deployed as a Databricks App.

## Architecture
- **Frontend**: Flask templates (Jinja2) with static CSS/JS
- **Backend**: Python Flask with modular blueprints
- **Deployment**: Databricks Apps via Declarative Automation Bundles (DABs)
